# Anern Inverter

Моніторинг інвертора Anern та передавання телеметрії
до Home Assistant через MQTT.

## 1. Обладнання

- Інвертор: Anern FGI-DU4200
- USB–RS232 адаптер: FTDI FT232R
- Сервер: Debian Linux
- Система автоматизації: Home Assistant

## 2. Принцип роботи

Python-програма отримує дані від інвертора
через послідовний інтерфейс.

Для опитування використовується протокол QPIGS.

Отримані дані обробляються та передаються
до MQTT-брокера.

## 3. Параметри зв'язку

- Послідовний порт: USB FTDI
- Швидкість: 2400 baud
- Команда опитування: QPIGS
- MQTT брокер: 127.0.0.1
- MQTT порт: 1883
- MQTT topic: anern_inverter/state

## 4. Програмне забезпечення

- Python 3
- PySerial
- Paho MQTT
- Mosquitto MQTT Broker
- Home Assistant

## 5. Запуск

Програма розташована в:

/opt/inverter/inverter.py

Системний сервіс:

inverter.service

## 6. Home Assistant

Дані передаються через MQTT
та використовуються для моніторингу
параметрів інвертора.
