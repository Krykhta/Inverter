# Резервне копіювання та відновлення Anern Inverter

## 1. Основні файли

- inverter.py — програма отримання даних від інвертора.
- requirements.txt — необхідні Python-бібліотеки.
- README.md — документація проєкту.

## 2. Розташування на робочому сервері

Програма встановлена в:

/opt/inverter/inverter.py

Системний сервіс:

inverter.service

## 3. Резервна копія

Перед зміною робочої програми необхідно зберегти поточну версію.

Рекомендовано зберігати резервну копію окремо від робочого файлу.

## 4. Відновлення проєкту

Клонування репозиторію:

git clone git@github.com:Krykhta/Inverter.git

Перехід до папки:

cd Inverter

Встановлення залежностей:

pip install -r requirements.txt

## 5. Встановлення на робочий сервер

Перед встановленням нової версії необхідно:

1. Перевірити код.
2. Зробити резервну копію поточної програми.
3. Перевірити доступність послідовного порту.
4. Переконатися в роботі MQTT.
5. Перевірити роботу Home Assistant.

## 6. Важливо

Не змінювати робочу версію на сервері без попередньої перевірки.

Не зберігати в GitHub паролі, токени та приватні ключі.
